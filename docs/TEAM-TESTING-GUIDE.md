## 3. Recommended Testing Flows & Checklists

### Flow 1: Athlete Journey (Student Portal - Port 3001)
1. **Login:** Enter mobile number and verify via OTP.
2. **Onboarding / Profile:**
   - Complete personal details, contact information, and date of birth.
   - Enter sports profile: Sport discipline, level (National/State/District), events, medal records (Gold/Silver/Bronze).
   - Enter academic background: High school / collegiate transcripts, GPA/percentage.
3. **Scholarship Discovery & Application:**
   - Browse university partners and eligible scholarship schemes.
   - Submit an application for an available program.
4. **Document Submission:**
   - Upload required identity proof (Aadhaar / Passport), certificates, and sports proof.
5. **Contract Review & E-signing:**
   - Review issued scholarship offers.
   - Accept offer and simulate digital signature.

### Flow 2: Staff & Operations Journey (Admin Portal - Port 3002)
1. **Login:** Use `+919999900001` with OTP.
2. **Application Processing:**
   - Navigate to `/applications`.
   - Review incoming athlete submissions and verify uploaded sports certificates.
   - Update application statuses (Under Review → Approved / Rejected).
3. **Scholarship & Award Management:**
   - Configure scholarship awards, discount tiers, and funding allocations.
   - Issue scholarship offers to athletes.
4. **University Catalog Management:**
   - Navigate to `/universities` to add or update university profiles, courses, intake capacity, and eligibility criteria.
5. **Financial Ledger & Analytics:**
   - Review payment schedules, fees, and disbursement records.

## 5. Useful DevOps Commands on EC2

To manage the platform from the EC2 terminal (`ssh -i aci-ec2-key.pem ec2-user@15.206.179.72`):

```bash
cd /home/ec2-user/AAI_scholarship_agency

# View real-time container status
sudo docker compose -f infra/docker/docker-compose.yml ps

# Follow logs of all services
sudo docker compose -f infra/docker/docker-compose.yml logs -f

# Follow logs of specific service
sudo docker compose -f infra/docker/docker-compose.yml logs -f notification-service
sudo docker compose -f infra/docker/docker-compose.yml logs -f auth-service
sudo docker compose -f infra/docker/docker-compose.yml logs -f api-gateway

# Re-run demo catalog seeding
npm run seed:demo

# Restart all services
sudo docker compose -f infra/docker/docker-compose.yml restart
```
